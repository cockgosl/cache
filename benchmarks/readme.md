## Workloads

- **LOOP** — циклическое обращение к небольшому рабочему набору страниц.
- **SCAN** — последовательный проход по большому набору уникальных страниц.
- **HOT/COLD** — несколько часто используемых страниц и большое количество редко используемых.
- **WORKING_SET** — периодическое изменение рабочего набора страниц.
- **MIXED** — комбинация различных типов обращений.
- **RANDOM** — псевдослучайная последовательность с фиксированным seed.

## Metrics

Для каждого алгоритма и workload измеряются:

- **Hits** — количество попаданий в кэш.
- **Hit ratio** — доля попаданий: `hits / requests`.
- **Ideal hits** — количество попаданий идеального кэша Белади.
- **Efficiency** — близость алгоритма к идеальному кэшу: `hits / ideal_hits`.

Для многоуровневого кэша дополнительно учитываются попадания на каждом уровне и обращения к памяти.
